
# 👤 Cartão de Perfil — Profile Card

Projeto de um cartão de perfil para redes sociais, desenvolvido com **HTML5 e CSS3** como parte de uma atividade prática do curso PROA.

O projeto tem como objetivo explorar a criação de componentes visuais modernos, utilizando organização de elementos, estilização de botões, ícones de redes sociais e efeitos interativos para construir uma interface de perfil atraente e organizada.

## Funcionalidades e características

- Cartão de perfil com design moderno e cantos arredondados.
- Foto de perfil circular com borda personalizada.
- Exibição de nome e profissão do usuário.
- Ícones de redes sociais com cores características de cada plataforma.
- Botões "Inscreva-se" e "Mensagem" com efeitos de hover.
- Indicadores visuais de curtidas, comentários e compartilhamentos.
- Layout centralizado com sombras e elementos organizados em seções.

## Tecnologias utilizadas

- **HTML5:** estruturação do cartão, informações do perfil, botões e indicadores.
- **CSS3:** estilização, posicionamento, sombras e efeitos interativos.
- **Flexbox:** alinhamento e distribuição dos elementos.
- **Boxicons:** utilização de ícones de redes sociais e interações.
- **Google Fonts:** utilização da fonte Poppins.

## Aprendizados

Durante o desenvolvimento, foram praticados conceitos como:

- Criação e estilização de componentes de perfil com HTML e CSS.
- Organização de elementos utilizando Flexbox.
- Aplicação de `border-radius` e `object-fit` em imagens circulares.
- Utilização de `::before` para criar elementos decorativos.
- Personalização de botões com `:hover` e `transition`.
- Aplicação de sombras com `box-shadow`.
- Utilização de `:last-child` para personalizar elementos específicos.
